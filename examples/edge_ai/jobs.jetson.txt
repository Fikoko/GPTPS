# A template for real jobs on a Jetson. Every job line is commented out, and its
# mem_mb is ???: nothing here was measured, and a declaration is only as good as
# the measurement behind it. A line uncommented with ??? still in it is refused.
#
# For each job:
#   1. Run it alone on the board, the way it will run in production, with
#      tegrastats in another terminal:
#          sudo tegrastats --interval 500
#      Note the RAM figure (the "RAM used/total MB" field) before the job starts,
#      and the highest it reaches while the job runs. The difference is the job's
#      peak. On a Jetson that one figure covers the CPU side and the GPU side: they
#      are the same DRAM. Run it a few times; inputs change the peak.
#   2. Put the peak plus a margin in mem_mb, and uncomment the line.
#   3. Give --budget-mb what the board can spare for these jobs: the RAM total less
#      what tegrastats shows with everything else that will be running - the OS,
#      the desktop if there is one, the always-on part of your pipeline.
#
# gpu_units are yours to define: they count GPU work, not GPU memory, which mem_mb
# already holds. Give every GPU job 1 and run with --gpu-slots N to allow N at a
# time, or weigh the heavier engines more. A CPU-only job can have 0.
#
# A command is split at spaces and run without a shell: no quoting, redirection,
# globbing or ~, and `#` ends the line here too. Anything more goes in a script.
# GPTPS buffers a job's stdout (up to 16 MiB; past that the job fails with
# GPTPS_E_IO), so a chatty tool's output belongs in a file its script writes.
#
# Before running CUDA jobs, read "Real CUDA jobs need the cgroup mode" in
# README.md: without GPTPS_CGROUP_PARENT each job runs under RLIMIT_AS set to its
# mem_mb, and CUDA cannot initialise under that.
#
# The paths below are placeholders for your own engines, scripts and data, and the
# timeouts and retries are starting points, not advice: a timeout a few times the
# job's usual run, and retries only for a job that can fail and then succeed.
#
# name            mem_mb  gpu  timeout_s  retries  command
